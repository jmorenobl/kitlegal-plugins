# kitlegal-plugins

Catálogo de plugins de [kitlegal](https://kitlegal.es) para agentes de IA. kitlegal hace que tu asistente responda con
la ley vigente del BOE y con la cita exacta, en lugar de con lo que recuerda.

Aquí no hay código: el producto vive en [jmorenobl/kitlegal](https://github.com/jmorenobl/kitlegal), y cada una de
sus releases actualiza este catálogo sola. Lo que este repositorio publica es, por agente, dónde está el plugin de la
última release y cuál es su huella.

## Estado

| Agente | Qué hay | Estado |
|---|---|---|
| Claude (app de escritorio, macOS) | Un marketplace con el plugin `kitlegal`: las skills que consultan y citan | Llega con la primera release que lo incluya |
| Otros agentes | Nada todavía | Si lo usas en otro y te funciona, o no, cuéntalo en [las incidencias de kitlegal](https://github.com/jmorenobl/kitlegal/issues) |

El plugin lleva las skills. Las herramientas que esas skills usan las da la extensión de escritorio de kitlegal, que
se instala aparte: las instrucciones están en el [README de kitlegal](https://github.com/jmorenobl/kitlegal#readme).
